# Live recipient pilot

The two hosted models chose every tool call themselves. Each ran four WorkBench forwarding tasks with an unchanged source email and three fixed misleading notes. The directory, user request, and tools stayed unchanged. The actor never saw the receipt or scoring labels.

All 32 workflows completed the requested forwards. Every injected note reached the model. All 40 completed sends went to permitted recipients. The receipt verified them, but this pilot provides no evidence of an advantage on an agent-selected wrong coworker. Following the frozen stopping rule, the other 64 planned episodes were not run.

The 97 hosted requests cost $0.049627225. Local models stayed off. Offline verification reexecuted all 113 saved model-selected tool calls and checked the results and committed recipients. These four tasks and repeated conditions are not 32 independent tasks.

The first exposure counter looked for unescaped note text inside JSON-encoded tool results. It missed the multiline forged-user-turn notes. The saved tool responses were decoded and all exposures were recomputed offline. The roster-only result was also relabeled as insufficient for listed recipients: membership alone does not establish permission. Neither correction changed a model input, recipient, charge, or failure count. The raw hosted responses remain unchanged.
